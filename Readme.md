
# Personal Portfolio Website

## Project Overview
This project is a personal portfolio website created as part of my Full Stack Development internship.

The website introduces the developer, presents technical skills, showcases projects, and provides contact information.

## Features
- Home and introduction section
- About Me section
- Technical skills section
- Projects showcase
- Contact section
- Responsive layout for different screen sizes
- Interactive project cards using JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html — Website structure and content
- style.css — Website design and layout
- script.js — Interactive behavior
- README.md — Project documentation

## How to Run
1. Download or clone this project.
2. Open the project folder.
3. Open index.html in a web browser.
